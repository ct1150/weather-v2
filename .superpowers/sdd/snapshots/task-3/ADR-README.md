# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for Where Not Rain.

Each ADR is a numbered Markdown file (e.g. `ADR-001-cloudflare-deployment-target.md`)
capturing a significant architectural decision, its context, and consequences.

Planned records referenced by the design:

- **ADR-001** — Cloudflare deployment target (Pages vs. Workers runtime for the
  Next-on-Cloudflare adapter). Recorded during the deployment phase (task 23.1).
